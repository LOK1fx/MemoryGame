# Gamejam game project created in a week

Game was created during Future Inspire Jam #4 in a single week by two people. <br>
[lok1fx](https://github.com/LOK1fx) - lead programming, animations, rig, models, levels, editor tools <br>
[midlmm](https://github.com/midlmm) - programming, "buttons level" designer, ideas
